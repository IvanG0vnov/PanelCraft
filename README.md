# PanelCraft

**Параметрический дизайн мебели и оптимизация раскроя — полностью в браузере.**

PanelCraft — небольшое приложение для мастерской: проектируйте корпусную мебель по параметрическим шаблонам, получайте полную спецификацию деталей и размещайте их на стандартных листах с наглядными картами раскроя. Приложение не требует сборки, серверной части и внешних библиотек.

**Разделы:** Конструктор · Детали · Раскрой · Материалы · Проект

## Быстрый старт

**Вариант 1 — просто открыть**

Откройте `panelcraft/index.html` в современном браузере. Приложение работает по `file://` и хранит все данные в `localStorage`.

**Вариант 2 — локальный HTTP-сервер (рекомендуется)**

```bash
cd panelcraft
python -m http.server 8765
```

Затем откройте <http://127.0.0.1:8765>.

Node.js, npm и подключение к интернету не нужны.

## Возможности

### Конструктор

- Три параметрических шаблона: **корпусный шкаф**, **комод**, **стеллаж**.
- Ширина, высота, глубина, полки, двери, секции дверей, ящики, цоколь, зазор дверей, задняя стенка.
- Изометрический 3D-предпросмотр обновляется при изменении параметров.
- Три режима предпросмотра: **Фасад**, **Схема** (внутренние полки и фасады) и **3D**.
- Перетаскивание маркеров на фасаде и схеме меняет ширину и высоту с шагом параметра; маркеры работают и с клавиатуры.
- Полки, двери, секции дверей и ящики настраиваются кнопками прямо в предпросмотре; счётчики дублируются в подвале.
- Каждая дверь делится по высоте на 1–4 равные секции; между секциями используется общий зазор фасадов.
- В режиме **Схема** нажмите на полку, чтобы убрать её или вернуть; подвал показывает активное и общее количество полок. Убранные полки исключаются из спецификации, раскроя и 3D.
- Добавление, дублирование, переименование и удаление изделий в проекте.
- Материалы корпуса, фасадов и задней стенки для каждого изделия.

### Детали и спецификация (BOM)

- Автоматическое формирование панелей: боковины, верх и низ, полки, двери, корпуса и днища ящиков, цоколь, задние стенки.
- Сводная таблица деталей: количество, размеры, материал, толщина, кромка и направление текстуры.
- Поиск и фильтр по материалу; редактируемые пользовательские детали.
- Показатели количества деталей, площади панелей, длины кромки и стоимости материала.
- Раскрой учитывает кромку и фиксацию текстуры.

### Оптимизация раскроя

- **MaxRects** с эвристиками BSSF и BAF и несколькими порядками сортировки; для каждого материала выбирается лучший результат.
- **Гильотинный** алгоритм с прямыми сквозными резами — для форматно-раскроечного станка.
- Настройка пропила, обрезки листа, минимального делового остатка и поворота деталей.
- Детали с фиксацией текстуры и детали из текстурированных материалов никогда не поворачиваются.
- Наглядные SVG-карты раскроя по каждому листу с процентом отходов, полезной площадью и стоимостью.
- Предупреждения о деталях, которые не помещаются на лист.
- Список деловых остатков по каждому листу.
- Экспорт в CSV и печатный отчёт A4.

### Материалы

- Ширина и высота листа, толщина, цена, цвет и признак текстуры.
- Добавление, редактирование и удаление материалов; материал, используемый в деталях, удалить нельзя.
- Количество листов, отходы и стоимость по каждому материалу в разделе раскроя.

### Проект

- Автосохранение в `localStorage` после каждого изменения.
- Интерфейс RU / EN, светлая / тёмная тема; настройки сохраняются.
- Резервная копия в JSON и импорт (с версионированием схемы и нормализацией при импорте).
- Демонстрационный проект, пустой проект, сброс к демо и очистка локальных данных.
- Выбор валюты (RUB, BYN, EUR, USD, KZT, UAH, GBP).

В демонстрационном проекте **Кухня «Ольха»** — 4 изделия и 54 детали. С настройками MaxRects по умолчанию для него требуется 7 листов.

## Экспорт

| Файл | Содержимое |
| --- | --- |
| `*_parts_YYYY-MM-DD_HHMM.csv` | Спецификация: деталь, материал, толщина, длина, ширина, количество, кромка, текстура, источник |
| `*_cutting_YYYY-MM-DD_HHMM.csv` | Одна строка на размещение: лист, материал, размер листа, деталь, размер, X/Y, поворот, кромка |
| `*_YYYY-MM-DD_HHMM.json` | Полный проект (схема 1); импортируется через **Проект → Импорт JSON** |

Файлы CSV сохраняются в UTF-8 с BOM и разделителем `;`, поэтому корректно открываются в Excel с русской локалью. Размеры указаны в миллиметрах; в русском интерфейсе используется десятичная запятая.

Печатные стили формируют отчёт A4 в книжной ориентации с двумя картами раскроя в ряд; навигация, настройки и панели инструментов скрываются.

## Структура проекта

```text
panelcraft/
├─ index.html            # оболочка приложения, спрайт иконок, порядок скриптов
├─ css/
│  └─ app.css            # дизайн-система, адаптивные и печатные стили
└─ js/
   ├─ i18n.js            # словари RU/EN и форматирование
   ├─ data.js            # утилиты, значения по умолчанию, демо/пустой проект, нормализация
   ├─ model.js           # генерация параметрических деталей и итоги
   ├─ optimizer.js       # раскрой MaxRects + гильотина, остатки, предупреждения
   ├─ exporters.js       # CSV спецификации/раскроя и JSON проекта
   ├─ ui.js              # модальные окна, подтверждения, уведомления, иконки, метрики
   ├─ app.js             # маршрутизация, сохранение, тема/язык, оболочка
   └─ views/
      ├─ designer.js
      ├─ parts.js
      ├─ cutting.js
      ├─ materials.js
      └─ project.js
```

Приложение использует классические теги `<script>` и глобальные пространства имён (`Utils`, `Data`, `Model`, `Optimizer`, `Exporters`, `UI`, `Views`, `App`) — без сборщика и ES-модулей. Порядок скриптов важен: `i18n → data → model → optimizer → exporters → ui → views → app`.

### Добавление раздела

1. Создайте `js/views/myview.js` и зарегистрируйте `window.Views.myview = { render, mount }`.
2. Подключите скрипт в `index.html` перед `js/app.js`.
3. Добавьте кнопку навигации с `data-route="myview"` и строки `page.myview.*` в `js/i18n.js`.
4. Добавьте имя маршрута в `ROUTES` в `js/app.js`.

### Добавление шаблона

Расширьте `TEMPLATES`, `PARAM_RANGES` и `baseParams()` в `js/data.js`, затем добавьте соответствующую генерацию деталей в `js/model.js`.

## Данные и конфиденциальность

- Все данные хранятся локально под ключом `panelcraft.state.v1` (тема и язык — под `panelcraft.theme` / `panelcraft.lang`).
- Сетевых запросов, аналитики и внешних сервисов нет.
- Команда **Проект → Опасная зона → Очистить локальные данные** удаляет сохранённое состояние и после перезагрузки восстанавливает свежий демонстрационный проект.
- Перед крупными изменениями скачайте резервную копию JSON.

## Поддержка браузеров

Современные Chromium, Firefox и Safari. Приложение использует CSS Grid, SVG, `structuredClone` (с запасным вариантом через JSON), `Intl.NumberFormat` и `color-mix`; полифилы не включены.

## Проверка

Проверено в браузере Edge (headless) на десктопе и при реальном размере области просмотра 390×844:

- Все пять разделов отрисовываются без ошибок в консоли.
- При ширине 390 px страница не переполняется по горизонтали; мобильная навигация и одноколоночные раскладки работают.
- Предпросмотр проверен для всех трёх шаблонов: переключение режимов, изменение полок/дверей/секций/ящиков, перетаскивание ширины и высоты, сохранение после перезагрузки и корректная работа после переключения изделий.
- Секции дверей: 1–4 секции умножают количество фасадов в спецификации и корректно отрисовываются в фасаде, схеме и 3D; при нулевом количестве дверей управление секциями скрывается.
- Удаление полок: полки убираются и возвращаются кликом в режиме «Схема», количество деталей и подвал обновляются, выбор сохраняется после перезагрузки и обрезается при уменьшении числа полок.
- CSV спецификации, CSV раскроя и JSON скачиваются и корректно разбираются (UTF-8 BOM, разделитель `;`, ожидаемое количество строк и столбцов).
- Цикл «экспорт JSON → разбор → нормализация → импорт» сохраняет 4 изделия, 27 строк / 54 детали и 7 листов.
- Проект сохраняется после перезагрузки; очистка локальных данных действительно восстанавливает демонстрационное состояние.
- Печатные стили скрывают элементы управления, располагают карты в две колонки и формируют PDF A4.
